Add a phone

Plug a phone into this PC by USB to make it a camera, or to put right one whose settings have drifted. Each step is looked at first and left alone when it is already as it should be.

No camera app is published on this manager yet, so a phone cannot be given it, by cable or by code. Under System › Cameras & devices › Camera app, press Check GitHub for a newer app and publish the newest one; then come back here.

Without a cable: a code for a reset phone

A factory-reset phone can be made a camera by scanning a code on this screen: no cable, no Developer options. The phone fetches the app from the internet, checks it is signed with this installation’s key, and sets itself up.

The camera it becomes
Wi-Fi to set up over (it needs the internet)
Camera network (leave empty when it is the same one) The phone moves to this network when its set-up is finished, and forgets the first one once it has reached the manager.

The passwords go into the code and nowhere else: the manager does not keep them. Anyone who photographs the code has both, and can pair as this camera until the phone has.

  1. Reset the phone, or take a new one out of its box. Do not start its set-up.
  2. On the very first screen (“Hi there” or “Welcome”), tap the same empty spot six times. A camera opens.
  3. Point it at this code. The phone joins the Wi-Fi, fetches the app and sets itself up; follow what it asks, and skip any sign-in.
  4. When the phone has finished, it appears on the Cameras page. Set a screen lock on it afterwards.

Preparing a phone from scratch

These are the parts only a person holding the phone can do. They take about ten minutes, once per phone. After them, everything else is done from this page.

1. Start from a reset phone

  1. If the phone has been used before, reset it: Settings › System › Reset options › Erase all data (factory reset). On a Samsung: Settings › General management › Reset › Factory data reset. This erases everything on the phone.
  2. If it was signed in to a Google or Samsung account, remove that account before resetting (Settings › Passwords and accounts). Otherwise the phone asks for that account again after the reset.

2. Go through the phone’s first-time set-up, signing in to nothing

  1. Choose the language and carry on.
  2. When asked to connect to Wi-Fi, join the camera network. If the phone then insists on an account, go back and choose Set up offline or Skip instead, and join the camera network afterwards in Settings.
  3. Do not sign in to a Google account. Choose Skip, Set up offline or Not now. On a Samsung, skip the Samsung account as well. This is the step that matters most: Android lets the app manage the phone remotely only if the phone has no accounts on it.
  4. Do not copy apps or data from another phone.
  5. Set a screen lock (a PIN) when offered, and note it. The cameras are meant to stay locked.
  6. Decline the extras: Google services, backup, assistant, fingerprint and face unlock are not needed.

3. Switch on Developer options

  1. Open Settings › About phone. On a Samsung: Settings › About phone › Software information.
  2. Tap Build number seven times, and enter the screen lock PIN if asked. The phone says “You are now a developer”.

4. Switch on USB debugging

  1. Open Settings › System › Developer options. On a Samsung: Settings › Developer options, at the bottom of Settings.
  2. Switch on USB debugging and confirm.

5. Plug it into this PC

  1. Use a cable that carries data; some cables only charge.
  2. Unlock the phone. It asks Allow USB debugging? Tick Always allow from this computer and tap Allow.
  3. The phone appears at the top of this page within a few seconds. Choose what it should be and press Set up this phone.

If something does not go as described

  • The phone does not appear here. Try another cable or USB port, unlock the phone, and check that USB debugging is still on. If the phone asks what the USB connection is for, either answer will do.
  • It appears, but says it has not allowed this computer. Unplug it and plug it in again with the screen unlocked, then tap Allow.
  • “The phone has accounts on it.” Remove them in Settings › Passwords and accounts and run the set-up again. If that is not enough, reset the phone and skip the sign-in.
  • It is set up but does not connect. Check it is on the camera network. After a phone has been restarted, its screen lock has to be entered once before it can connect.
